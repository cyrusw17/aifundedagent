# Needlewood V4: Engagement audit

Engagement today: C (5.1/10). With hooks: A- (8.8/10). Design judgement, not data. Target: compelling, not predatory.

## 13 levers (today -> with hooks)
Core action feel 5->9; Variable rewards 6->9; Anticipation/near miss 3->9; Goal gradient 4->9; Loops at every time scale 4->9; Collection completion 8->9; Daily habit 3->8; Return reward 6->9; Social proof 5->8; Identity/status 8->9; Progression/prestige 5->8; Mastery 3->8; Healthy engagement 6->9.

## Loop ladder
10s dig swipe (ring, near miss) / 2min find + polish / 10min Stack + bounties + almost-there bars / 1h codex set / 1 day idle line + daily bounties + forgiving streak / 1 week thread hunt + server Golden Needle / 1 month Re-Stack prestige / 1 season story chapter with vote.

## Hooks (playable in prototype/dig-test.html)
Rarity-tinted glint; "So close!" near miss; polish-to-reveal mutations (Giant x2, Rainbow x3, Glitch x4, Cosmic x10); luck meter pity timer (+25% per Steel/Bronze, full = next find +1 tier); find combo (45s window, up to x2.5); bounties + "almost there" goal-gradient bars; idle line (6/min, 8h cap) and forgiving daily streak (one-day freeze); simulated server feed; screen shake, flash, haptics, rising chime.
Planned: set bonuses + museum; skill tricks (mastery); hats/titles/base display; server-wide secrets; Re-Stack prestige.

## Guardrails
Do: show odds; earn all needles/mutations in play; forgiving streaks, returning limited items; natural stop points; parental tools.
Don't: paid random boxes (Roblox requires odds disclosure for paid random items); countdown purchase pressure; punishing absence; fake scarcity; deceptive feeds (prototype feed is labeled simulated).

## Metrics (targets to test)
Second-Stack start rate: most; D1 >= 35%; D7 >= 12%; session 15-25 min; half of week-one players reach a set bonus.
