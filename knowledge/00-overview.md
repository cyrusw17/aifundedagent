# Overview — How Smart Money Thinking Works

## Origin lineage (context, not trivia)

SMC did not appear from nowhere. The idea that large operators move markets and leave footprints goes:

1. **Wyckoff** — Composite Man, accumulation/distribution, springs & upthrusts
2. **Larry Williams / Linda Raschke** — Inner Circle framing, Turtle Soup (fade failed breakouts)
3. **ICT (Michael Huddleston)** — Forex/session language, Order Blocks, FVG, PD Arrays, Killzones, IPDA framing
4. **Community SMC / educators (incl. TJR)** — Simplified operational checklists for discretionary day trading

You do not need every ICT acronym. You need the **mechanics**: liquidity → displacement → imbalance → retrace into array → continuation toward next liquidity.

## Four principles that unlock everything

1. **Markets seek liquidity** — Stops and pending orders cluster at obvious highs/lows (equal highs/lows, session extremes, prior day H/L). Price often raids them before the real move.
2. **Price rebalances inefficiency** — Aggressive displacement leaves Fair Value Gaps; price frequently revisits them.
3. **Structure reveals intent** — HH/HL = bullish delivery; LH/LL = bearish. BOS continues; CHoCH/MSS warns of a shift.
4. **Time filters quality** — Same pattern in a killzone ≠ same pattern at Asia lunch. Session + AMD (Power of 3) matter.

## Learning order (internalize in this sequence)

1. Market structure (BOS / CHoCH / MSS) + dealing ranges
2. Liquidity (BSL/SSL, internal vs external, inducement)
3. Displacement + FVG
4. Order blocks, breakers, mitigation
5. Premium / discount / OTE / PD arrays
6. Daily bias + Power of 3 (AMD)
7. Killzones + Silver Bullet
8. Confluence stacking + TJR-style execution routine
9. Risk, psychology, journaling (non-negotiable for funding)

## What “funded trader” discipline adds

- Fixed **risk per idea** (commonly 0.25–1% depending on firm rules)
- **One narrative per session** — do not flip bias every 5 minutes
- Prefer **A+ confluence** over frequency
- Journal: bias → liquidity draw → sweep → MSS → entry array → R-multiple → emotional state
