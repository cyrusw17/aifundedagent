# Glossary — ICT / SMC / TJR Terms

| Term | Meaning |
| --- | --- |
| BSL | Buy-side liquidity above highs |
| SSL | Sell-side liquidity below lows |
| BOS | Break of structure (continuation) |
| CHoCH | Change of character (early shift) |
| MSS | Market structure shift (shift with intent/displacement) |
| FVG | Fair value gap / imbalance |
| IFVG | Inverse fair value gap (failed/flipped imbalance) |
| OB | Order block |
| BB | Breaker block |
| EQ | Equilibrium (50% of range) |
| OTE | Optimal trade entry (~0.62–0.79 retrace) |
| PD Array | Premium/discount entry tools map |
| AMD / PO3 | Accumulation, Manipulation, Distribution |
| Killzone | High-probability session time window |
| Silver Bullet | Timed one-hour FVG scalp model |
| Inducement | Trap liquidity inside range |
| Displacement | Impulsive institutional candle(s) |
| Mitigation | Return into array to rebalance/fill |
| SMT | Divergence between correlated markets |
| Draw on liquidity | Magnet/target for price delivery |
| IRL / ERL | Internal / external range liquidity |
| PDH/PDL | Previous day high/low |
| Judas Swing | Manipulation move opposite true daily direction |
| Turtle Soup | Fade of failed breakout / stop run |
| POI | Point of interest (array/zone you care about) |
