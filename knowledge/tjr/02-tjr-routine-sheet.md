# TJR-Style Daily Routine Sheet

## Pre-session (before London or before NY, depending on your desk)

- [ ] HTF bias stated in one sentence (bullish / bearish / no trade)
- [ ] Dealing range marked; note premium vs discount
- [ ] Liquidity map drawn:
  - [ ] PDH / PDL
  - [ ] Asia high / low
  - [ ] London high / low (if trading NY)
  - [ ] 4H / 1H swing highs & lows
  - [ ] Equal highs / lows
- [ ] Primary draw on liquidity chosen (target narrative)
- [ ] News check (high-impact red-folder events)
- [ ] Max risk for day defined (firm rules)

## During session

- [ ] Wait for key level **sweep**
- [ ] Confirm LTF order-flow change (MSS/BOS, inverse FVG, decisive close)
- [ ] Identify continuation confluence (FVG / EQ / OB / breaker)
- [ ] Enter only after zone interaction + directional push (per model)
- [ ] Stop beyond sweep extreme
- [ ] TP1 internal liquidity / nearest key level; TP2 external draw
- [ ] If thesis invalidates, flat — no revenge

## Post-session

- [ ] Screenshot annotated narrative (bias → sweep → shift → entry → management)
- [ ] Grade setup: A / B / C
- [ ] Note emotional errors separately from strategy errors
- [ ] Update stats: WR, avg R, time-of-day expectancy

## Session focus suggestions

| Desk | Focus |
| --- | --- |
| London | Asia range raid + AMD manipulation |
| NY AM | Highest participation; Silver Bullet 10–11 ET optional |
| NY PM | Only if clear continuation/reversal narrative remains |

## Personalization notes
Use this sheet as a skeleton. Lock **your** instruments, risk %, minimum RR, and which killzone you actually trade. Consistency > trading every session.
