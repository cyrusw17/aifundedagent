# Confluence Framework — How Pros Stack Conditions

Confluence is not “more indicators.” It is **independent conditions agreeing** on the same trade idea.

## The A+ stack (minimum narrative)

Trade only when most of these align:

1. **HTF Bias** — Daily/4H structure + dealing range location (premium/discount)
2. **Draw on Liquidity** — Clear target (PDH/PDL, equal H/L, HTF swing, opposing FVG)
3. **Liquidity Event** — Sweep/raid of opposing liquidity (or engineered inducement taken)
4. **Displacement + Shift** — Impulsive move + BOS/MSS/CHoCH in trade direction
5. **PD Array Entry** — Retrace into OB / FVG / breaker / OTE in the correct half of range
6. **Time Filter** — Killzone or Silver Bullet window (or session open expansion)
7. **Risk Geometry** — Stop beyond sweep extreme; RR to next liquidity ≥ model minimum (often ≥ 1:2)

If 1–2 are missing, pass. Frequency is not the edge — **selection** is.

## Confluence scoring (practical)

| Factor | Weight | Pass condition |
| --- | --- | --- |
| HTF bias clear | High | Structure + narrative not conflicted |
| Premium/discount aligned | High | Buys in discount / sells in premium |
| Liquidity sweep first | High | Stops taken before entry narrative |
| Displacement + FVG | High | Not a slow grind break |
| Array + OTE overlap | Medium | OB/FVG inside 0.62–0.79 |
| Killzone timing | Medium | London / NY AM preferred |
| SMT / correlated confirmation | Optional | ES vs NQ, EUR vs GBP, etc. |
| News filter | High | Avoid blind entries into high-impact prints unless that *is* the model |

**A+**: all High factors + at least one Medium  
**B**: most High factors, weaker timing/refinement  
**C / skip**: fighting premium-discount, no sweep, or choppy Asia mid-range

## Multi-timeframe confluence (top-down)

```
Weekly/Daily → bias & major draws
4H/1H       → dealing range, POI (OB/FVG), session narrative
15m         → MSS confirmation, clearer FVG
5m/1m       → precise entry trigger & stop
```

Do not reverse a Daily bias because a 1m candle wiggled.

## Confluence anti-patterns (avoid)
- Entering every FVG
- Calling MSS on every micro swing
- Buying premium “because OB”
- Trading mid-range with no draw
- Ignoring session (dead hours)
- Moving stops emotionally after invalidation
