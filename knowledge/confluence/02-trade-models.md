# Canonical Trade Models (Narrative Templates)

These are reusable stories. Memorize the story, not random labels.

## Model A — Sweep → MSS → FVG/OB Retrace (core SMC)

1. Mark HTF bias and draw on liquidity
2. Wait for price to **raid** opposing liquidity
3. Require **displacement** creating MSS/CHoCH
4. Mark the displacement FVG and/or originating OB
5. Enter on retrace into array (optional CE / OTE refine)
6. Stop beyond swept extreme
7. Target internal then external liquidity along the draw

## Model B — Power of 3 (AMD day)

1. Asia builds range (accumulation)
2. London/NY prints Judas swing (manipulation) against eventual direction
3. Distribution expands toward daily draw
4. Enter on first high-quality PD array after manipulation confirms
5. Manage toward PDH/PDL / weekly liquidity

## Model C — Silver Bullet

1. Bias + draw prepared before window
2. Only trade inside SB hour
3. Liquidity sweep + displacement FVG inside window
4. Enter FVG retrace; scalp toward session liquidity (often 20–30 pip FX / points on indices style targets depending on instrument)

## Model D — Turtle Soup / failed breakout

1. Obvious level (session high, equal highs, prior day)
2. Break beyond level **fails** quickly
3. Displacement back inside range
4. Enter on retest of broken level / breaker / FVG
5. Target opposite side of range / next liquidity

## Model E — Continuation after BOS

1. Trend already confirmed by BOS in bias direction
2. Pullback into discount (bull) or premium (bear)
3. LTF CHoCH with trend + FVG hold
4. Target next external liquidity
5. Trail under/above successive HLs/LHs

## Invalidation doctrine
If price **closes** beyond your sweep extreme / OB invalidation with displacement against you, the idea is dead. Do not “average.” Reassess bias first.
