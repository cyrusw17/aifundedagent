# Pre-Trade Checklist (Agent / Trader)

Print this mentally before every order.

## Narrative
1. What is HTF bias?
2. Where is the draw on liquidity?
3. What opposing liquidity was swept?
4. Where did structure shift (which candle / which TF)?
5. Which PD array am I using, and is it in premium/discount correctly?
6. Why now (killzone / SB / session expansion)?

## Risk
1. Stop price is **beyond** invalidation (sweep extreme / OB invalidation)
2. Position size from stop distance (not gut feel)
3. RR to first target acceptable
4. Daily loss limit not threatened
5. No stacked correlated risk that breaches firm rules

## Go / No-Go
- **GO** only if narrative answers are crisp and risk is mechanical
- **NO-GO** if you are bored, chasing, or “kinda see an FVG”
